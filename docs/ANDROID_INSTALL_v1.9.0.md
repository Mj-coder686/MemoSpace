# MemoSpace Android v1.9.0 安装说明

1. 把 `MemoSpace-v1.9.0-release.apk` 发送到安卓手机并安装。
2. 如果系统提示来源未知，请只为当前文件管理器临时允许安装未知应用。
3. 首次打开后使用现有 MemoSpace 账号登录，默认连接正式站点 `https://memospace.fun`。
4. 相机、相册、定位和通知权限都可以按需授权；拒绝其中一项不会影响其他基础功能。
5. 新版本沿用 MemoSpace 的固定签名，可以覆盖安装之前由同一签名发布的版本并保留应用数据。

## 本版主要变化

- 上传大图时会先在手机端压缩，列表页优先加载缩略图，减少流量和服务器压力。
- 设置页可以看到个人文件用量与剩余空间。
- 已加入系统通知权限、设备登记、通知点击跳转及后端推送通道。
- Android 状态栏会根据浅色/深色界面调整图标可读性。

## 关于系统通知

安装包已经包含通知功能，但正式后台推送还需要项目自己的 Firebase 配置文件与服务器凭据。未配置时，站内实时通知仍正常工作，设置页会明确显示“等待推送服务配置”，不会误报为已开启。

部分中国大陆版小米系统缺少或限制 Google Play 服务，Firebase 通知可能延迟或无法送达。若实机验证不稳定，后续需要接入小米推送服务，不能仅靠应用代码规避系统限制。

## V1.2 浏览器流程

1. 三个用户分别注册并取得不同的 12 位纯数字 Memo ID。
2. A 使用 B 的 Memo ID 查找并发送好友申请，B 接受。
3. B 关闭 A 的“直接创建提醒”权限。
4. A 与 B 同时进入聊天页，A 的消息通过 WebSocket 实时到达 B；B 刷新后仍能读取历史。
5. 非好友 C 请求 A 的聊天历史得到 403。
6. A 给 B 创建带真实 PNG 的提醒；B 看到“等待确认”并能实际解码图片。
7. 非参与者 C 请求提醒图片得到 403；B 接受后提醒正常生效。
8. 到期提醒由调度器写入站内通知。

## V1.4 三账号浏览器流程

1. A、B、C 分别注册，确认每人取得唯一 Memo ID，实时连接建立。
2. A 搜索 B 并发送好友申请，B 不刷新页面即可收到实时提示并接受。
3. A 的好友页自动出现 B；A 从好友卡片选择关系分类并发送关系申请。
4. B 实时收到关系申请，接受后双方进入同一个 Relationship Space。
5. A 上传并保存头像，页面通过鉴权媒体接口实际解码显示；不能把他人文件设为头像。
6. A 设置账号背景颜色和背景图片，调节亮度与遮罩并刷新验证持久化。
7. A 设置共同空间主题和背景图，B 可以查看；非成员 C 请求该图片返回 403，也不能修改空间外观。
8. A 创建纪念日并跳转到年度提醒预填；创建当天 Memory 后，日历能够展开实际内容。

## 复现命令

```bash
cd backend
mvn test

cd ../frontend
npm run build
npx playwright test e2e/v11-full-journey.spec.ts e2e/v12-social-reminder.spec.ts e2e/v14-profile-appearance-invitation.spec.ts
```

Docker 前端通过 Nginx 提供静态资源并代理 `/api` 与 `/ws`；开发模式可以用 `MEMOSPACE_E2E_BASE_URL=http://localhost:5173` 运行同一套浏览器验收。

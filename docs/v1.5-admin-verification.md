# MemoSpace V1.5 管理与交互验收记录

## 本轮结果

- 增加独立管理员入口 `/admin/login`，用户登录与管理员登录使用滑动切换控件。
- 管理员会话只允许进入账号管理 API；普通产品页面使用独立用户会话。
- 管理员可按用户名、昵称或 Memo ID 检索账号，重置临时密码，修改 12 位纯数字 Memo ID，并查看审计记录。
- 管理员账号对普通用户不可搜索、不可关注，也不能成为好友或关系邀请目标。
- 页面路由使用短距离、低干扰过渡；系统开启“减少动态效果”时自动停用动画。
- Docker Compose 顶层项目名固定为 `memo-space`，五个容器在 Docker Desktop 中作为同一个可展开项目显示。

## 隐私验证

后端测试先由真实用户创建 PRIVATE Memory 并上传真实图片，再使用管理员 Token 请求对应 Memory、文件内容、空间和聊天接口，全部返回 403。浏览器只读验收再次检查管理员 Token 对 Memory、文件、空间和通知接口的统一拦截。管理员目录只包含账号管理所需的最小字段，不提供内容浏览能力。

应用级管理员隔离不等同于端到端加密。持有主机、数据库或对象存储根权限的人仍属于基础设施信任边界；若产品未来面向不受信任的服务器运营方，需要另行设计端到端加密。

## 本地默认管理员

- 入口：`http://localhost:3000/admin/login`
- 用户名：`admin`
- 初始密码：`MemoAdmin2026!`

默认值只适合本地体验。首次创建后不会被环境变量覆盖，正式使用前应登录管理中心修改管理员密码，并更换 `.env` 中的 JWT、数据库、Redis 与 MinIO 密钥。

# MemoSpace Web 社交与提醒迭代清单

本轮只完善 Web 产品和共享后端，不包含 Web Push、Android APK 或 iPhone 客户端。

## 1. 数字身份与添加好友

- [x] 注册时自动生成唯一、不可修改的 12 位纯数字 Memo ID。
- [x] 数据库内部主键继续只供系统使用，Memo ID 单独存储。
- [x] 用户可随时修改昵称，昵称允许重复。
- [x] 设置页、个人主页和搜索结果显示 Memo ID，并提供复制入口。
- [x] 支持通过完整 Memo ID 精确查找用户。

## 2. 好友关系

- [x] 发出、收到、接受和拒绝好友申请。
- [x] 好友列表、好友备注、删除好友与拉黑。
- [x] 好友和“恋人/家人”等关系绑定保持为两个独立层级。
- [x] 每个好友可单独设置是否允许对方直接创建提醒、是否静音聊天。
- [x] 重复申请、自加好友、越权处理和拉黑后的请求都由后端阻止。

## 3. WebSocket 一对一聊天

- [x] WebSocket 首帧 JWT 鉴权，未认证连接不能发送消息。
- [x] 只有已接受的好友可以私聊。
- [x] 消息持久化、客户端消息 ID 幂等、发送确认、已读状态和历史分页。
- [x] 在线状态、实时新消息、断线重连和离线历史补取。
- [x] Nginx 正确代理 WebSocket Upgrade。

## 4. Web 提醒中心

- [x] 支持生日、纪念日、任务、计划和自定义提醒。
- [x] 支持单次、每天、每周、每月和每年重复。
- [x] 支持个人提醒、关于好友的私人提醒、好友指派和关系共同提醒。
- [x] 好友指派根据好友权限直接生效或进入待确认。
- [x] 支持提醒图片、完成、稍后提醒、接受、拒绝和删除。
- [x] 到期提醒写入站内通知，并在用户在线时通过 WebSocket 实时送达。
- [x] 使用数据库唯一投递记录防止重复提醒。

## 5. 验收

- [x] 后端集成测试覆盖 Memo ID、好友权限、聊天持久化与提醒周期/投递。
- [x] 两个以上浏览器账号走完添加好友、实时聊天、离线历史和提醒流程。
- [x] 核对 MySQL、WebSocket Network、图片 HTTP、Docker 与服务日志。
- [x] Docker 重启后数据完整、迁移幂等，现有 V1.1 关系与媒体流程不回归。

## 6. 重要日期与日历联动（V1.3）

- [x] 共同空间纪念日支持创建、修改和删除，并显示距下一次纪念日的倒计时。
- [x] 纪念日可以一键带入提醒中心，创建每年重复提醒。
- [x] 日历日期可以展开当天的真实 Memory，而不只是显示数量。
- [x] 新 Memory 与重要日期变化通过站内实时连接通知相关用户。

## 7. 资料与个性化外观（V1.4）

- [x] 用户可编辑昵称、简介、所在地、性别、生日和头像。
- [x] 头像使用受控文件上传；用户不能把其他人的文件设为自己的头像。
- [x] 全站除浅色/深色外，支持自定义背景色、背景图片、图片亮度和遮罩强度。
- [x] 上传背景图后自动分析图片明暗并给出可读性更好的亮度与遮罩值，仍允许手动调整。
- [x] 每个关系共同空间可独立设置主题、颜色、背景图片、亮度和遮罩。
- [x] 共同空间背景图仅成员可读取，非成员访问返回 403。

## 8. 关系申请可靠送达（V1.4）

- [x] 好友申请、好友接受、关系申请和关系接受均通过 WebSocket 实时通知。
- [x] 好友卡片提供明确的“申请关系”入口，可选择分类并填写留言。
- [x] 收到关系申请时通知列表自动刷新，顶部显示未读提示和实时消息。
- [x] 浏览器端验证申请落库、实时送达、接受后分类出现对方并进入唯一共同空间。

## 9. 朋友社区管理与交互细化（V1.5）

- [x] 增加数据库管理员标识、首次启动默认管理员和独立管理员登录。
- [x] 增加管理员专用 JWT、后端拦截器和独立管理页面。
- [x] 管理员可检索账号、重置临时密码、修改唯一 12 位 Memo ID，并保留审计记录。
- [x] 管理员账号不进入普通用户搜索、关注、好友与关系邀请体系。
- [x] 管理员 Token 无法读取 Memory、媒体、空间、聊天、提醒、通知或 WebSocket。
- [x] 登录页提供用户/管理员滑动切换，普通页面增加轻量流畅过渡并尊重“减少动态效果”系统设置。
- [x] Docker Compose 项目名固定为 `memo-space`，Docker Desktop 将五个服务归入同一可展开项目组。
- [x] 后端 21 项测试、生产构建、Docker 健康检查及管理员只读浏览器验收通过。
